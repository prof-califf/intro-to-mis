Python Bootcamp: Analysis with pandas

About 3 to 5 hours, at your own paceRedo your Excel work in code →

All quarter you have analyzed Cascadia's sales in Excel, Tableau, and SQL. Python is the fourth tool, and the one analysts reach for when a question needs many steps, a lot of data, or the same work done again next month. This bootcamp teaches enough Python to be useful and then the library that does the real work, pandas. Everything runs in your browser. There is nothing to install.

WhyWhy Python, if you already have Excel

Excel is the right tool until the work gets big, repetitive, or long. Big: a worksheet stops at 1,048,576 rows, and a year of website visits or card swipes passes that quickly. Repetitive: the same clean-up of the same export every Monday is an hour you spend again and again. In Python you write the steps once and rerun them on next month's file in seconds. Long: when an analysis takes twenty steps, a spreadsheet full of hand edits cannot tell anyone what you did. Code is a written record of every step, so a coworker, or you in six months, can check it and run it again.

Python is also where most data science and AI work happens. The tools for statistics, machine learning, and the language models in Chapter 12 are mostly used from Python. You will not build a model in this bootcamp, but you will be able to read the code the analysts and engineers around you write, and ask better questions about it.

Where you would use it

Finance: rebuild the monthly report from the raw export with one click. Marketing: combine exports from three tools that never line up. Operations: check every store's numbers for anything unusual, every week, automatically. Any role: clean a messy file the same way every time.

1Python in ten minutes

About 20 minutes. Python runs top to bottom. A name on the left of = stores whatever is on the right. A list holds several values in order. A for loop repeats the indented lines once per item. print shows a result.

Line by line
  • price = 289.00 Stores the number 289 under the name price. Nothing prints; Python just remembers it.
  • sale_price = price * (1 - discount) Does the math with the stored names, the same as an Excel formula that points at cells. * multiplies.
  • print(round(sale_price, 2)) Shows the result, rounded to two decimal places.
  • stores = ["Seattle Flagship", ...] A list: several values in square brackets, in order. Text goes in quotes.
  • for s in stores: Repeats the indented line once per item. Each time through, s holds the next store name. The colon at the end is required.

Indentation is not decoration in Python. The indented lines are the ones inside the loop. Now add things up with a loop:

Line by line
  • total = 0 Starts a running total at zero, before the loop.
  • for amount in sales: Visits each number in the list, one at a time.
  • total = total + amount Takes the old total, adds this amount, and stores it back as the new total. After the last item, total holds the sum.
  • print(total) Not indented, so it runs once, after the loop is finished.

2Loading data: a spreadsheet in code

About 20 minutes. pandas loads a CSV file into a DataFrame, which is a table with named columns, much like a sheet in Excel. By convention it is called df. This file is the same cascadia-sales-2025.csv you used in Tableau.

Line by line
  • import pandas as pd Loads the pandas library and gives it the short name pd. Every pandas tool now starts with pd.
  • pd.read_csv("cascadia-sales-2025.csv") Reads the file into a table. Each row is a sale; each column is a field from the CSV.
  • df = ... Stores that table under the name df so later cells can use it.
  • df.head() Shows the first five rows. It is the first thing to run on any new data, to see what you are working with.

When the last line of a cell is a value, the cell shows it, so you do not always need print. A few more ways to look at a table:

Line by line
  • df.shape The size of the table as (rows, columns). No parentheses after shape: it is a fact about the table, not an action.
  • df.columns.tolist() The column names as a list. Use it whenever you forget how a column is spelled.
  • # (rows, columns) Anything after # is a comment. Python ignores it; it is a note for people.
  • df["store"].value_counts() df["store"] picks one column. .value_counts() counts how many rows have each value, largest first.

3Filtering: keeping the rows you want

About 30 minutes. Put a condition in square brackets and pandas keeps the rows where it is true. Combine conditions with & (and) or | (or), each condition in its own parentheses. len() counts the rows left.

Line by line
  • df["store"] == "Tacoma" Checks every row: is the store Tacoma? The answer is a column of True and False. Two equals signs means "is equal to"; one means "store this".
  • df[ ... ] Putting that True/False column inside df[ ] keeps only the True rows.
  • len(tacoma) Counts the rows that are left.
  • ( ... ) & ( ... ) Both conditions must be true. Each one needs its own parentheses, or Python reads the line in the wrong order and gives an error.

4Grouping: the pivot table of pandas

About 30 minutes. groupby splits the table into groups, does a calculation in each, and puts the results back together. It is GROUP BY from SQL and a pivot table from Excel, in one line.

Line by line
  • df.groupby("store") Splits the table into one pile of rows per store.
  • ["revenue"] In each pile, look only at the revenue column.
  • .sum() Adds up each pile. Swap in .mean(), .count(), .max(), or .min() for other questions.
  • .sort_values(ascending=False) Sorts the result, largest first. ascending=True (or leaving it out) sorts smallest first.

Change sum() to mean() and you get the average revenue per sale at each store, a different question from total revenue.

5Dates and new columns

About 40 minutes. The CSV stores dates as text. pd.to_datetime turns them into real dates, and then .dt pulls out pieces: month, weekday, and so on. You make a new column by assigning to a name that does not exist yet.

Line by line
  • pd.to_datetime(df["sale_date"]) Turns text like "2025-03-14" into real dates that Python can do date math on.
  • df["sale_date"] = ... Writes the converted dates back over the old column.
  • .dt.month .dt unlocks date tools. .month gives 1 to 12; .day_name() gives Monday, Tuesday, and so on.
  • df["month"] = ... Assigning to a column name that does not exist yet creates a new column.
  • .size() Counts the rows in each group: the number of sales, not the revenue.

size() counts rows in each group, so that is the number of sales per month, not revenue.

6Pivots and joins

About 40 minutes. pivot_table builds the same grid as an Excel pivot table: one dimension down the side, one across the top, a number in the middle.

Line by line
  • pivot_table(index="store", ...) index is what goes down the side, one row per store.
  • columns="category" What goes across the top.
  • values="revenue", aggfunc="sum" The number in the middle, and how to combine it: add up revenue for each store and category.
  • grid.round(0) Rounds to whole dollars for display. It does not change the numbers stored in grid.
  • grid.loc["Tacoma", "Water"] Reads one cell: the row name first, then the column name.

Read one cell with .loc[row, column], for example grid.loc["Tacoma", "Water"].

Module 6One cell of the pivotAnswer goes in Checkpoint 9

The CSV does not say what kind of membership each member has. That lives in the members table in the database you queried in Lab 7. pandas can read it straight from the database with SQL, then merge it onto the sales, which is a JOIN:

Line by line
  • sqlite3.connect("cascadia.db") Opens the same database file you queried in Lab 7.
  • pd.read_sql("SELECT ...", con) Runs a SQL query and hands back the result as a pandas table. Every SQL skill still works here.
  • df.dropna(subset=["member_id"]) Drops sales with no member attached, because they have nothing to join to.
  • .merge(members, on="member_id") The JOIN: matches each sale to its member by member_id and adds the member_type column.
  • groupby(["member_type", "member_id"]) Groups by two things at once, so you get each member’s total for the year.
  • per_member.groupby("member_type").mean() Then averages those yearly totals within each membership type.

That is the average total a member spent in 2025, by membership type. Two groupbys in a row: the first adds up each member's year, the second averages those totals.

7Charts

About 20 minutes. pandas draws charts with a library called matplotlib. The first chart takes a few seconds more while it loads.

Line by line
  • import matplotlib.pyplot as plt Loads the charting library under the short name plt.
  • monthly.plot(kind="line", marker="o", ...) pandas draws the chart from the grouped numbers: months along the bottom, revenue up the side. Try kind="bar".
  • plt.ylim(bottom=0) Starts the vertical axis at zero.
  • plt.show() Draws it. Here, the chart appears under the cell.

plt.ylim(bottom=0) starts the axis at zero, so the dips look as big as they are and no bigger. Try deleting it and running again to see the difference.
