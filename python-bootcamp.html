Optional · Extra credit

Python for Business: Analysis with pandas

About 3 to 5 hours, at your own paceRedo your Excel work in code →

All quarter you have analyzed Cascadia's sales in Excel, Tableau, and SQL. Python is the fourth tool, and the one analysts reach for when a question needs many steps, a lot of data, or the same work done again next month. This bootcamp teaches enough Python to be useful and then the library that does the real work, pandas. Everything runs in your browser. There is nothing to install.

WhyWhy Python, if you already have Excel

Excel is the right tool until the work gets big, repetitive, or long. Big: a worksheet stops at 1,048,576 rows, and a year of website visits or card swipes passes that quickly. Repetitive: the same clean-up of the same export every Monday is an hour you spend again and again. In Python you write the steps once and rerun them on next month's file in seconds. Long: when an analysis takes twenty steps, a spreadsheet full of hand edits cannot tell anyone what you did. Code is a written record of every step, so a coworker, or you in six months, can check it and run it again.

Python is also where most data science and AI work happens. The tools for statistics, machine learning, and the language models in Chapter 12 are mostly used from Python. You will not build a model in this bootcamp, but you will be able to read the code the analysts and engineers around you write, and ask better questions about it.

Where you would use it

Finance: rebuild the monthly report from the raw export with one click. Marketing: combine exports from three tools that never line up. Operations: check every store's numbers for anything unusual, every week, automatically. MIS: move data between two systems that do not talk to each other. Business analytics: a model that flags customers likely to leave, rerun every month. Any role: clean a messy file the same way every time.

Who this is for, and what you get

It is optional, and no programming background is assumed. If you have written an Excel formula, you can do this. You learn in 42 short steps, one idea at a time, and you write every line of code yourself. Pass every step, write a short memo, and upload your certificate and your code to the Python for Business assignment in Canvas. Each bootcamp you finish adds 2 points to the exam of your choice; name the exam in your Canvas submission. Do it in several sittings; your progress saves in this browser.

For a resume: Completed a 42-step Python bootcamp: data cleaning, filtering, grouping, pivots, joins, and charts in pandas on a 2,899-row retail dataset. The resume page shows where it goes.

Green · AI as coach

Python error messages are long. Paste one into an AI and ask what it means; that is a good use. Then fix the code yourself. Do not ask it to write the code for a step. Writing code yourself is the skill, and the certificate says you have it.

Python runs in your browser

Every code box is live Python, and they all share one session, so a name you make in one step is there in the next. If you come back later, the steps you already passed are set up again for you when you run the next one.

The first run starts Python and loads pandas, which takes 10 to 30 seconds on a laptop and longer on a phone. After that it is quick. A laptop is easier than a phone for this bootcamp.

ToolThe sandbox: your scratch space

The dark box below is not a step, and nothing in it is graded. It is a place to try things: check a column name, test a filter before you trust it, or try an idea before you put it in a step. It shares the same Python session as every cell on the page, so once you have run the cell that loads df, the sandbox can use it too. Press Dock and it follows you down the page.

Sandbox · tool, not a step

The sandbox is docked at the bottom of the screen. Press Undock on it to put it back here.

How the steps work

Each step teaches one small idea, then gives you a task. Write the code in the box and press Run and check. If it is right, the next step opens. If not, you get a note on what to fix. Every step has a hint, and after two tries you can see a solution. There is no penalty for wrong tries.

Your progress and your code save in this browser, so you can stop and come back. In the code box, Tab adds an indent; press Esc and then Tab to move on. To start over, use the button.
